## 二、论文整体概述

### 1. 核心问题

论文关注两个核心问题：

1. 当前细胞 AI 基础模型在肾脏病理这一单器官、但细胞形态和染色类型高度复杂的场景中，是否已经能够可靠完成细胞核实例分割。
2. 如何在减少像素级专家标注成本的前提下，利用现有基础模型生成伪标签，并结合专家对困难样本的修正，提升肾脏细胞核分割性能。

论文指出，虽然已有细胞分割基础模型在广泛细胞类型、显微镜类型和实验条件下表现良好，但肾脏病理具有较高细胞多样性，且 PAS 等肾脏常用染色在通用训练数据中较少出现。因此，通用细胞基础模型是否足以直接用于肾脏核分割仍不清楚。同时，像素级实例分割标注成本高，需要更高效的 human-in-the-loop 数据富集策略。

### 2. 整体方法

论文构建了一个多中心、多疾病、多物种的肾脏病理评估与微调框架。整体流程包括：

1. 从 2542 张肾脏全切片图像中构建评估数据集，随机提取 512×512 的 40× 图像 patch，并过滤低质量或不可用 patch，最终形成 8818 个评估 patch。
2. 使用三个细胞基础模型 Cellpose、StarDist 和 CellViT 对肾脏图像 patch 进行细胞核实例分割推理。
3. 由两名受病理训练的学生进行盲评，对每个模型预测结果按 “good”、“medium”、“bad” 分级；分歧样本由经验丰富的肾脏病理学家复核。
4. 将多模型预测结果进行规则级融合：任一模型评为 good，则该 patch 被视为 good；所有模型均评为 bad，则该 patch 被视为 bad；其余为 medium。
5. 将多模型一致认可为 good 的样本作为 “easy” 伪标签数据，用于扩大训练集。
6. 将多模型一致评为 bad 的困难 patch 作为 “hard” 样本，由病理学家进行像素级人工标注。
7. 使用 easy 伪标签、hard 人工标注，或二者组合，对三个基础模型进行持续微调，并使用加权过采样缓解 easy 与 hard 样本不平衡。
8. 在独立保留测试集上用 Recall、Precision 和 F1 score 评估微调后的分割性能。

### 3. 主要贡献

1. 建立了面向肾脏病理细胞核分割的大规模、多中心、多疾病、多物种评估基准，覆盖 2542 张肾脏全切片图像和 8818 个 512×512 图像 patch。
2. 提出一种 human-in-the-loop 多模型数据富集策略：利用多个基础模型预测结果进行评级筛选，将专家标注集中在共识困难样本上，从而降低像素级标注成本。
3. 对 Cellpose、StarDist 和 CellViT 三个细胞基础模型进行系统评估和微调，证明 easy 伪标签与 hard 专家修正样本组合能够稳定提升模型性能；其中微调后 StarDist 在论文报告结果中取得最高 F1 score 0.8229。

## 三、方法总结

### 方法 1：Human-in-the-loop 多模型数据富集与持续微调框架

#### 1. 核心思想与解决的问题

- **目标问题**：如何在肾脏病理细胞核实例分割中评估并改进现有细胞基础模型，同时减少对昂贵像素级专家标注的依赖。
- **现有方法的局限**：
  - 通用细胞基础模型虽然跨域能力较强，但在肾脏病理这一特定器官场景中仍存在性能缺口。
  - 肾脏 WSI 具有高细胞多样性，且 PAS 等染色在通用训练数据中较少出现。
  - 像素级实例分割标注成本高，论文中提到困难 patch 的人工标注大约需要 20 分钟/patch。
  - 已有 human-in-the-loop 流程通常围绕单一模型构建，多模型组合用于数据富集的潜力未被充分探索。
- **核心思想**：不直接让专家修正所有模型预测，而是先使用多个基础模型生成预测，再通过人工评级筛选样本。多模型一致评为 good 的样本作为 easy 伪标签，扩大训练规模；多模型一致评为 bad 的样本作为 hard 样本，交由病理学家进行高质量像素级标注。随后使用这些富集数据对基础模型进行微调。
- **创新点**：
  - 作者声称的创新：多模型预测与 human-in-the-loop 评级结合的数据富集框架，以及将专家标注优先分配给共识困难样本。
  - 由本地实验证据支持的创新：easy 伪标签与 hard 专家修正样本的组合微调在多个模型上带来性能提升；不同训练数据比例、hard 样本增量实验和交叉验证结果支持该策略的有效性。
  - 需要注意：该创新主要是数据筛选、标注策略和微调流程层面的创新，而不是提出新的分割网络架构。

#### 2. 详细结构与数据流

- **输入**：
  - 2542 张肾脏全切片图像，来源包括公开数据集和 Vanderbilt University Medical Center 内部数据。
  - 公开来源包括 KPMP、NEPTUNE 和 HUBMAP，共 1449 张 WSI，占 57%。
  - 内部来源共 1093 张 WSI，占 43%。
  - 样本包括人类和啮齿类肾脏组织。
  - 染色类型包括 H&E、PASM 和 PAS。
  - 每张 WSI 随机提取四个 512×512 像素、40× 放大倍率的图像 patch。
  - 过滤污染、低成像质量、死亡组织或染色方法错误的 patch 后，得到 8818 个评估 patch。

- **数据预处理**：
  - 从 WSI 中随机提取 512×512 patch。
  - 使用 40× 放大倍率。
  - 丢弃污染、低质量、死亡组织或染色错误的 patch。
  - 构建评估数据集：8818 个图像 patch。
  - 构建微调数据集：共 12005 个图像-标签对，其中包含多模型 good 预测形成的 easy 伪标签，以及 198 个由病理学家人工标注的 hard patch。
  - 微调数据划分：11807 对用于训练，100 对用于验证。
  - 独立测试集：另外 185 张由病理学家标注的图像，来自所有肾脏 WSI 来源。
  - 论文声明训练/验证所用 WSI 与保留测试集之间没有重叠。
  - 每个 512×512 patch 包含约 50–300 个细胞核。

- **单模态编码**：
  - 本文为单模态病理图像分割，不涉及文本、基因组或其他模态编码。
  - 图像编码和分割预测由三个现有细胞基础模型完成：
    1. Cellpose：使用 U-Net backbone 预测拓扑图的水平梯度、垂直梯度以及二值图，并通过梯度跟踪算法形成细胞边界。
    2. StarDist：使用 U-Net backbone 预测对象概率和从细胞核中心到边界的径向距离，形成星凸多边形；后处理使用非极大值抑制，并可结合测试时增强和模型集成。
    3. CellViT：使用 U 形层级 encoder-decoder Vision Transformer 结构；encoder 使用在 104 million 组织学图像上预训练的 ViT256 权重，并在 PanNuke 数据集上进一步训练；后处理遵循 HoVer-Net 风格，使用水平和垂直距离梯度图进行边界 delineation。

- **跨模态融合**：
  - 本地文本中不存在真正的跨模态融合，因为输入只有病理图像，没有文本、基因组、转录组等第二模态。
  - 论文中的“融合”主要是多模型预测结果的规则级融合，而不是特征级跨模态融合。
  - 多模型评级融合规则：
    1. 如果任一模型将某 patch 评为 good，则该 patch 被融合评级为 good。
    2. 只有所有模型都将某 patch 评为 bad 时，该 patch 才被融合评级为 bad。
    3. 其余情况评为 medium。
  - 该融合用于数据筛选和困难样本识别，不用于最终预测头的特征融合。

- **处理流程**：
  1. 对 8818 个评估 patch 使用 Cellpose、StarDist、CellViT 分别进行细胞核实例分割推理。
  2. 两名受病理训练的学生对模型预测进行盲评，评级为 good、medium、bad；不一致样本由经验丰富的肾脏病理学家复核。
  3. 根据评级标准，good 预测定义为捕获约 90% 的细胞核，bad 预测定义为捕获少于 50% 的细胞核，其余为 medium。
  4. 对三个模型的评级进行规则级融合，得到融合后的 easy/bad 样本分布；融合后 good patch 为 6001 个，占 68%，bad patch 为 534 个，占 6%。
  5. 收集多模型 good 预测及对应图像作为 easy 伪标签数据。
  6. 选择被所有模型一致评为 bad 的 198 个 hard patch，由病理学家进行像素级人工标注。
  7. 构建富集训练集，共 12005 个图像-标签对。
  8. 使用加权过采样策略缓解 easy 与 hard 样本约 50:1 的不平衡；在所有同时使用 easy 和 hard patch 的实验中，过采样因子 γs = 0.85。
  9. 对三个基础模型分别进行微调，训练设置包括仅 easy、仅 hard、easy+hard，以及 25%、50%、75%、100% 不同训练数据比例；另设置 10% 数据实验。
  10. 在独立保留测试集上使用 Recall、Precision 和 F1 score 评估分割性能。

- **输出**：
  - 每个图像 patch 的细胞核实例分割 mask。
  - 每个模型预测的人工评级标签：good、medium、bad。
  - 多模型融合评级结果。
  - 微调后模型在测试集上的 Recall、Precision、F1 score。
  - 富集训练数据：easy 伪标签数据和 hard 专家标注数据。

- **模块在整体网络中的位置**：
  - 该方法不是单一网络模块，而是覆盖数据生成、人工质控、训练集构建和模型微调的完整框架。
  - 三个基础模型既是被评估对象，也是伪标签生成器。
  - 人工评级模块位于模型推理之后、训练数据构建之前。
  - 微调模块位于数据富集之后，用于更新基础模型参数。

- **与其他模块的连接方式**：
  - 基础模型推理结果输入人工评级模块。
  - 人工评级结果决定哪些样本成为 easy 伪标签，哪些样本进入 hard 人工标注。
  - easy 和 hard 数据共同进入加权过采样与微调模块。
  - 微调后的模型可再次用于下一轮预测和数据富集；论文讨论中提到随着模型适应肾脏域，预计下一轮 HITL 微调可产生更好的 curation 结果。

#### 6. 实现提示

- **关键网络组件**：
  - Cellpose：U-Net backbone、水平/垂直梯度预测、二值图预测、梯度跟踪后处理。
  - StarDist：U-Net backbone、对象概率预测、径向距离预测、星凸多边形表示、非极大值抑制、测试时增强、模型集成。
  - CellViT：U 形层级 Vision Transformer encoder-decoder、ViT256 预训练权重、PanNuke 训练、HoVer-Net 风格的水平/垂直距离图后处理。
  - 数据富集组件：多模型推理、人工评级、easy 伪标签收集、hard 样本专家标注、加权过采样。

- **重要超参数**：
  - 过采样因子 γs = 0.85，用于所有同时使用 easy 和 hard patch 的实验。
  - 包含 easy patch 的微调实验训练 50 epochs。
  - 仅使用 hard patch 的微调实验训练 25 epochs。
  - batch size = 16。
  - 训练数据比例实验：25%、50%、75%、100%。
  - 额外低数据实验：10% easy 标签，N = 1181；10% hard 标签，N = 20；以及二者组合。
  - hard patch 数量：198。
  - 评级类别：good、medium、bad。
  - good 标准：约捕获 90% 细胞核。
  - bad 标准：捕获少于 50% 细胞核。

- **归一化/激活方式**：

  - 图像级评级不能完全反映局部 mask 质量，可能遗漏细粒度错误。
  - 论文讨论中提到，Cellpose 在训练时将 512×512 图像转换为 grayscale nuclear bands，可能导致信息损失，尤其对染色较浅、形态复杂的 hard 图像不利。

  - 需要选择或训练适合目标域的多个基础分割模型。
  - 需要重新定义 good/medium/bad 评级标准，或由目标域专家制定标准。
  - 需要收集目标域 WSI 或 patch 数据，并进行质量控制。
  - 需要识别目标域中的 hard patch，并安排专家像素级标注。
  - 需要根据 easy/hard 比例调整加权过采样因子。
  - 需要重新验证训练数据比例、微调轮数和测试指标。

- **适用条件**：
  - 目标任务是细胞核或类似实例分割任务。
  - 存在可用的预训练分割模型，能够生成初始预测。
  - 有病理专家或受训人员可以进行评级和少量高质量标注。
  - 目标域与预训练域存在明显差异，导致基础模型性能不足。
  - 数据量足以支持微调；论文实验表明过少数据会降低收益。

- **潜在限制**：
  - 依赖伪标签质量，基础模型较弱时可能引入噪声。
  - 评级类别只有 good、medium、bad，粒度较粗。
  - 图像级评级可能无法反映局部错误。
  - 评级者之间可能存在主观差异。
  - 不同基础模型对目标域的适配程度不同，hard 样本并不一定对所有模型都有益。
  - 论文结果显示，当训练数据减少到 10% 时，性能增益变小，CellViT 在极小数据下甚至可能低于基线。

#### 9. 实验与消融证据

- **主要性能结果**：
  - 在 8818 个评估 patch 的人工评级中，CellViT 的 good 预测比例为 63.6%，高于 Cellpose 的 40.5% 和 StarDist 的 40.2%。
  - 多模型融合评级后，good patch 比例提高到 68%，bad patch 比例降低到 6%。
  - 在独立测试集基线性能中，CellViT F1 score 为 0.7838，StarDist 为 0.7380，Cellpose 为 0.6748。
  - StarDist 基线 Precision 为 0.9158，Recall 为 0.6331，说明其漏检一定数量细胞核。
  - 微调后，StarDist 取得论文中报告的最高 F1 score 0.8229，且该最佳结果来自使用 hard 标签的设置。
  - Cellpose 微调后 F1 score 从 0.67 提升至 0.75。
  - CellViT 在 hard patch 增量消融中，当所有 hard patch 被包含时达到 F1 score 0.798；论文同时指出 CellViT 最优策略是同时使用 easy 和 hard 标签。

- **相对基线的提升**：
  - 三个模型在富集数据微调后均较基线有所提升。
  - StarDist 从基线 F1 0.7380 提升到最高 0.8229。
  - Cellpose 从基线 F1 0.6748 提升到约 0.75。
  - CellViT 基线已经最高，提升幅度相对较小，但仍通过 easy+hard 策略获得改进。
  - 论文结论认为，easy 伪标签与 hard 专家修正 patch 的组合是最有效且适用范围最广的策略。

- **相关消融实验**：
  - 不同训练数据比例消融：比较 25%、50%、75%、100% 训练数据下的表现。
  - 低数据比例消融：使用 10% easy 标签、10% hard 标签及组合，发现性能增益变小，但 CNN-based 模型总体趋势仍保持一致；CellViT 在数据过少时性能下降更明显。
  - hard patch 增量消融：逐步加入 pathologist-corrected hard patch，观察对不同模型的影响。
  - 标注策略消融：比较仅 easy、仅 hard、easy+hard。
  - 模型一致性分析：计算模型间 agreement matrix，最高一致性为 Cellpose 与 StarDist，为 0.76；最低为 Cellpose 与 CellViT，为 0.67。
  - bad 样本一致性：bad 样本具有最高三模型一致性，超过 70%，支持将共识 bad 样本优先交给专家标注。
  - 评估者一致性：在随机选择的 300 张图像上，CellViT 的两名评估者一致性最高，为 94.3%。
  - 5-fold 交叉验证：论文提到在补充材料中比较不同训练标注策略下的 F1 score。

- **作者结论**：
  - 肾脏病理细胞核分割仍需要更面向器官的基础模型。
  - 多模型预测与 human-in-the-loop 数据富集能够减少专家像素级标注负担，并提升模型性能。
  - easy 伪标签和 hard 专家修正样本的组合具有广泛适用性。
  - 不同基础模型因预训练域差异，对 hard 样本的响应不同；Cellpose 作为 fluorescent-dominant 模型，在加入 hard H&E 样本时表现不如 H&E-dominant 模型稳定。

- **证据是否充分**：
  - 对“富集微调能提升三个基础模型性能”这一核心结论，本地正文提供了基线、微调结果、不同数据比例、hard patch 增量和一致性分析等证据，证据较充分。
  - 对“多模型组合优于单模型”的证据主要体现在融合评级后 good patch 增加、bad patch 减少，以及模型间非完全一致性；但论文没有提供特征级融合或最终预测级集成的完整定量比较。
  - 对伪标签噪声和域差异的解释有一定实验趋势支持，但本地文本未提供完全隔离变量的定量证明。
  - 加权过采样公式和补充实验细节不在本地正文中，因此部分实现与统计细节证据不足。

#### 11. 一句话总结

本文提出了一种面向肾脏病理细胞核分割的 human-in-the-loop 多模型数据富集框架，通过多模型预测评级筛选 easy 伪标签并集中专家标注 hard 样本，再用加权过采样微调 Cellpose、StarDist 和 CellViT，以较低标注成本提升肾脏域分割性能。

## 四、论文级综合评价

### 1. 最值得借鉴的方法

最值得借鉴的是“多模型预测 + 人工评级 + 困难样本优先标注 + 伪标签微调”的数据富集流程。该设计将昂贵的像素级专家标注转化为更具扩展性的图像级评级，并把有限专家资源集中到多模型一致失败的 hard patch 上。对于计算病理中常见的标注瓶颈，这种策略具有较强实用价值。

此外，论文对三个基础模型进行一致性分析，发现 bad 样本具有最高三模型一致性，这为“优先标注共识失败样本”提供了直接依据。加权过采样用于缓解 easy/hard 样本不平衡，也是一个可借鉴的训练策略。

### 2. 方法之间的关系

本文只有一个核心命名框架，即 human-in-the-loop 数据富集与持续微调框架。Cellpose、StarDist 和 CellViT 不是本文提出的独立新方法，而是三个被评估和被微调的基础模型。

它们之间的关系如下：

1. 三个基础模型首先作为基线模型，用于评估在肾脏核分割上的初始能力。
2. 三个模型同时作为伪标签生成器，为 easy 样本提供预测 mask。
3. 人工评级模块对三个模型的预测进行质量筛选。
4. 多模型融合评级用于确定 easy 样本和 hard 样本。
5. 富集数据反过来用于微调这三个模型，形成持续学习闭环。
6. 论文中的“融合”主要是评级层面的规则融合，而不是特征级、注意力级或预测 mask 级的复杂融合。

### 4. 与当前研究方向的关系

- **可直接采用的设计**：
  - 使用多个预训练分割模型生成候选预测。
  - 用人工评级代替全量像素级修正。
  - 优先标注多模型一致失败的 hard patch。
  - 使用 easy 伪标签扩大训练集。
  - 使用加权过采样处理 easy/hard 不平衡。
  - 对基础模型进行域适配微调。

- **需要改造的设计**：
  - 若目标场景涉及多模态病理数据，例如 WSI 与文本、诊断报告、基因组或空间组学联合分析，需要重新设计真正的跨模态融合模块；本文没有此类模块。
  - 若希望提高融合质量，可从简单评级融合升级为不确定性融合、mask-level ensemble、特征级蒸馏或教师-学生框架。
  - 若评级噪声较大，可引入局部评级、区域级质量分数或自动不确定性估计。
  - 若目标域染色差异更大，需要更系统的颜色归一化、染色适配或域自适应策略。

- **可能形成的新研究思路**：
  - 基于多模型不确定性的主动学习：不仅选择共识 bad 样本，也选择模型高不确定性样本。
  - 器官特异性细胞基础模型：论文已指出肾脏域需要更针对性的基础模型。
  - 分割与分类联合训练：论文讨论中提到未来可让分类任务指导分割过程。
  - 将 HITL 数据富集扩展到 WSI 级诊断或预后任务，而不仅限于 patch 级核分割。
  - 在多模态病理学习中，将细胞核分割结果作为结构化中间表示，与文本或分子数据融合。
