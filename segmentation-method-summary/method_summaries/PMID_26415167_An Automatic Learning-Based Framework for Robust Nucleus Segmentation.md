## 二、论文整体概述

### 1. 核心问题

论文要解决组织病理学图像中细胞核自动分割的困难。正文指出主要挑战包括：细胞核相互接触或重叠、形状变化、核内强度不均匀、背景杂乱、对比度差以及边界弱或缺失。现有方法存在以下问题：

- 分水岭方法容易过分割，且依赖 marker 检测。
- 图或 Voronoi/Delaunay 类方法常依赖凹点检测或交互修正。
- 水平集或主动轮廓方法可能计算成本高，且隐式模型容易允许拓扑变化。
- 颜色分割或颜色归一化方法对染色变化敏感，且不一定能处理接触核。
- 形状先验方法多用于单对象分割，或难以直接用于多个接触细胞核。

### 2. 整体方法

论文提出一个学习式细胞核分割框架。整体流程为：

1. 训练一个深度卷积神经网络（CNN），用于判断图像块中心是否接近细胞核中心。
2. 测试时，CNN 以滑窗方式对图像生成概率图。
3. 对概率图进行阈值化和小区域去除。
4. 基于距离图的反图与 H-minima 变换，提出迭代区域合并算法，生成每个细胞核的初始形状。
5. 训练阶段同时用选择式字典学习构建紧凑细胞核形状库，并按形状聚类建立多个子模型。
6. 测试阶段交替执行：
   - 基于局部排斥参数主动轮廓的形状形变；
   - 基于选择式稀疏形状模型的形状推断。
7. 最终输出保持形状的单个细胞核轮廓。

### 3. 主要贡献

1. 提出基于深度 CNN 概率图与迭代区域合并的细胞核形状初始化方法，用于从复杂组织病理图像中获得每个细胞核的初始轮廓。
2. 提出选择式稀疏形状模型，通过从训练形状中选择代表性形状构建字典，并结合局部约束与鲁棒 ISE 目标进行形状建模。
3. 提出局部排斥参数可变形模型，将图像区域项、边缘项、局部邻域排斥项和形状先验结合，用于同时分割多个接触或重叠细胞核，并保持对象拓扑。

## 三、方法总结

### 方法 1：基于深度 CNN 与选择式稀疏形状模型的自动细胞核分割框架

#### 1. 核心思想与解决的问题

- **目标问题**：在组织病理学图像中自动分割单个细胞核，尤其处理细胞核接触、重叠、弱边界、缺失边界、背景杂乱和形状变化。
- **现有方法的局限**：
  - 分水岭方法易过分割，marker 检测依赖具体应用。
  - 图方法和凹点方法依赖准确的凹点或边界信息。
  - 水平集方法计算成本高，且隐式拓扑变化可能产生错误轮廓。
  - 颜色方法对染色差异敏感。
  - 传统形状先验方法多面向单对象，难以直接处理多个接触核。
- **核心思想**：结合底层图像外观信息与高层形状先验。CNN 提供鲁棒的前景概率图；迭代区域合并提供每个核的初始轮廓；局部排斥可变形模型利用图像证据驱动轮廓；选择式稀疏形状字典约束轮廓形状。
- **创新点**：
  - 作者声称的创新包括：迭代区域合并、选择式稀疏形状字典、局部排斥参数轮廓、多个形状子模型。
  - 使用 CNN 生成概率图本身不是本文唯一创新点；本文的关键差异在于将 CNN 概率图、形状初始化、稀疏形状先验和局部排斥轮廓演化组合为一个保持拓扑的细胞核分割框架。
  - 本文为单模态图像方法，不涉及新增模态或跨模态融合。

#### 2. 详细结构与数据流

- **输入**：
  - 组织病理学图像。
  - CNN 输入为以小像素为中心裁剪的图像块。
  - 脑肿瘤数据集使用 55×55×3 输入块。
  - NET 数据集使用 39×39 输入块，正文提到对应 64 个输出特征图。
  - 乳腺癌数据集使用 45×45 输入块。
  - 输入像素使用 YUV 颜色空间的原始像素值。
  - 具体整图尺寸未说明。

- **数据预处理**：
  - 使用原始像素值，颜色空间为 YUV。
  - 训练时以标注的细胞核几何中心为监督。
  - 若图像块中心距离标注核中心小于若干像素，正文选择 4 像素，则标为正样本，否则为负样本。
  - 正样本通过旋转 90°、180°、270° 进行增强。
  - 测试时使用与训练块相同尺寸的滑窗裁剪图像块。
  - 对部分超出图像边界的块使用零填充。
  - CNN 输出正类概率图后，使用阈值 \(q_1 = 0.5\) 去除低概率像素。
  - 使用面积阈值 \(q_2\) 去除小噪声区域：NET 为 30 像素，脑肿瘤为 70 像素，乳腺癌为 70 像素。
  - 对概率图计算距离图，并对距离图取反。
  - 使用 H-minima 变换，初始深度参数 \(dt_0 = 1\)。
  - 最终使用形态学操作平滑 marker。

- **单模态编码**：
  - 使用深度 CNN 对每个图像块进行二分类。
  - 最后一层为 softmax 层，输出两个概率，分别表示中心像素属于正类或负类。
  - 正类概率被解释为该像素接近细胞核中心的概率。
  - 脑肿瘤数据集的 CNN 结构包括：
    1. 输入层：55×55×3
    2. 卷积层：输出 50×50×48，卷积核 6×6
    3. 最大池化层：输出 25×25×48，池化核 2×2
    4. 卷积层：输出 22×22×48，卷积核 4×4
    5. 最大池化层：输出 11×11×48，池化核 2×2
    6. 全连接层：1024
    7. 全连接层：1024
    8. 输出层：2
  - 卷积层使用 ReLU 激活。
  - NET 与乳腺癌数据集的 CNN 结构类似，但输入尺寸不同；除 NET 的 64 个输出特征图外，其他细节未说明。

- **跨模态融合**：
  - 不适用。
  - 本地证据中只有组织病理图像这一种输入模态，没有文本、基因组、图谱或其他模态。
  - 形状先验与图像证据的结合属于同一图像模态内的先验约束与形变融合，不属于跨模态融合。

- **处理流程**：
  1. **训练 CNN 概率图模型**：使用标注核中心生成正负图像块，训练 CNN 输出像素级正类概率。
  2. **训练形状字典**：
     - 细胞核形状由轮廓上的 landmark 表示。
     - 主轴两端作为主要 landmark，其余 landmark 沿形状均匀插值。
     - 形状通过 Procrustes 分析对齐。
     - 每个细胞核轮廓由 60 个控制点表示。
     - 使用选择式字典学习从训练形状中选择代表性形状作为字典基。
     - 使用 k-means 将训练形状聚为多个类别，正文实验中每个数据集使用 3 个形状簇。
  3. **测试时生成概率图**：
     - 对测试图像进行滑窗 CNN 推理。
     - 得到每个像素属于细胞核中心附近的概率图。
  4. **概率图后处理与形状初始化**：
     - 对正概率图阈值化。
     - 去除小面积噪声区域。
     - 计算距离图及其反图。
     - 对反距离图应用 H-minima 变换获得初始 minima。
     - 对每个连通区域进行迭代区域扩张。
     - 若多个 marker 将在下一次迭代合并，则记录合并前的 marker 作为初始形状。
     - 非接触或非重叠核直接由预测区域平滑后作为初始形状。
  5. **轮廓形变**：
     - 对每个初始轮廓，使用局部排斥参数主动轮廓模型进行形变。
     - 能量项包括前景区域项、背景区域项、边缘项、局部排斥项和轮廓长度项。
     - 每个轮廓只考虑其局部邻域内的其他轮廓产生的排斥作用。
  6. **形状推断**：
     - 将当前测试形状对齐到各形状簇均值形状。
     - 选择对齐误差最小的形状模型作为活跃模型。
     - 使用稀疏形状字典对轮廓进行形状约束和推断。
  7. **交替优化**：
     - 框架交替执行形状形变与形状推断，直到轮廓稳定。
     - 最终输出每个细胞核的参数化轮廓。

- **输出**：
  - 每个细胞核的分割轮廓。
  - 每个轮廓由 60 个控制点表示。
  - 也可理解为输出细胞核分割掩码，但掩码具体维度未说明。
  - 中间输出包括概率图和初始形状。

- **模块在整体网络中的位置**：
  - CNN 是前端概率图生成模块。
  - 迭代区域合并是形状初始化模块。
  - 选择式稀疏形状模型是高层形状先验模块。
  - 局部排斥可变形模型是后端轮廓精分割模块。
  - 整体框架不是单一端到端网络，而是 CNN、形态学/区域合并、参数轮廓与稀疏形状模型的组合流程。

- **与其他模块的连接方式**：
  - CNN 输出概率图传给迭代区域合并。
  - 迭代区域合并输出每个核的初始轮廓。
  - 初始轮廓进入局部排斥可变形模型。
  - 形状字典在形状推断阶段约束轮廓。
  - 局部邻域关系可由初始化结果预先确定，用于降低排斥项计算量。

#### 3. 数学公式

以下公式仅在本地文本可可靠恢复时列出。

CNN 卷积层更新：

\[
P_j^l = f\left(\sum_i P_i^{l-1} * O_{ij}^l + \beta_j^l\right)
\]

其中 \(f(x)=\max(0,x)\) 为 ReLU。

普通稀疏形状表示目标：

\[
\min_{B,\{\alpha_i\}} \sum_{i=1}^{N} \|v_i - B\alpha_i\|_2 + \lambda \|\alpha_i\|_1
\]

选择式字典学习的 ISE 目标，按本地文本可恢复为：

\[
\min_{\theta} J(\theta)
=
\min_{\theta}
\left[
\left(
\int g(\epsilon|\theta)^2 d\epsilon
-
\frac{2}{N}\sum_{i=1}^{N} g(\epsilon_i|\theta)
\right)
+
\lambda
\sum_{i=1}^{N}
\sum_{k=1}^{K}
|\alpha_{ik}| \|v_i - b_k\|^2
\right]
\]

约束：

\[
1^T \alpha_i = 1, \quad \forall i
\]

其中 \(\epsilon_i = v_i - B\alpha_i\)。

固定字典后的稀疏编码目标：

\[
\min_{\{\alpha_i\}_{i\in A}}
\left[
\sum_{i\in A} \|v_i - B\alpha_i\|^2
+
\lambda
\sum_{k=1}^{K}
|\alpha_{ik}| \|v_i - b_k\|^2
\right]
\]

字典基替换相关性准则：

\[
COR(v_l, b_k^t, J_{b_k})
=
\frac{(v_l - b_k^t)^T(-J_{b_k})}
{\|(v_l - b_k^t)\|_2 \| -J_{b_k} \|_2}
\]

多轮廓能量函数：

\[
J =
\lambda_1 \sum_{i=1}^{N} \int_{\Omega_i} (I(\mathbf{x}) - u_i)^2 d\mathbf{x}
+
\lambda_2 \int_{\Omega_0} (I(\mathbf{x}) - u_0)^2 d\mathbf{x}
+
\lambda_3 \sum_{i=1}^{N} \int_0^1 e(v_i(s)) ds
+
\omega \sum_{i=1}^{N} \sum_{j=1,j\ne i}^{N} \int_{\Omega_i \cap \Omega_j} 1 d\mathbf{x}
+
\sum_{i=1}^{N} \gamma |v_i|
\]

其中边缘项选择为：

\[
e(v_i(s)) = -\|\nabla I(v_i(s))\|^2
\]

局部邻域排斥项：

\[
REP =
\omega
\sum_{i=1}^{N}
\sum_{j\in V_i}
\int_{\Omega_i \cap \Omega_j} 1 d\mathbf{x}
\]

轮廓演化方程：

\[
\frac{\partial v_i}{\partial t}
=
\left|
\frac{\partial v_i}{\partial s}
\right|
\mathbf{n}_i
\left(
-\lambda_1 (I-u_i)^2
+
\lambda_2 (I-u_0)^2
-
\lambda_3 \nabla e(v_i)
-
\omega \sum_{j\in V_i} z_j(v_i)
+
\gamma \rho(v_i)
\right)
\]

其中 \(z_j(\mathbf{x})=1\) 若 \(\mathbf{x}\in\Omega_j\)，否则为 0；\(\rho(\cdot)\) 表示曲率。

检测评估指标：

\[
P = \frac{TP}{TP+FP}, \quad
R = \frac{TP}{TP+FN}, \quad
F_1 = \frac{2PR}{P+R}
\]

## 四、论文级综合评价

### 1. 最值得借鉴的方法

最值得借鉴的是将“概率图初始化”与“形状先验约束下的局部排斥轮廓演化”结合。CNN 概率图提供较鲁棒的核位置与前景区域，迭代区域合并将接触区域拆分为每个核的初始形状，随后参数轮廓利用图像边界和局部排斥进行形变，稀疏形状字典再约束形状，避免弱边界导致的轮廓漂移或错误分裂。

### 2. 方法之间的关系

- CNN 是前端检测/概率估计模块。
- 迭代区域合并依赖 CNN 概率图，生成每个核的初始轮廓。
- 初始轮廓确定局部邻域关系，为局部排斥模型提供输入。
- 局部排斥可变形模型负责底层图像驱动的边界拟合。
- 选择式稀疏形状模型负责高层形状约束。
- 形变与推断交替进行，使底层图像证据和顶层形状先验共同决定最终分割。
