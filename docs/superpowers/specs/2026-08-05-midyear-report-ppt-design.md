# 年中汇报 PPT 设计（4 页）

日期：2026-08-05  
受众：混合（管理层 + 技术）  
侧重点：设计与功能亮点（方案 1）

## 目标

产出约 4 页中文 PPT，作为年中汇报材料，讲清项目定位、规模，以及三项核心设计亮点。

## 页面结构

### P1 项目定位与规模

- 标题：病理 AI 文献知识图谱与研究发现平台
- 一句话：把 PubMed 病理 AI 文献建成可查询、可辩论、可落地的知识资产，缩短「读文献 → 找空白 → 评估可行性 → 出方案」链路
- 规模（约）：论文 ~9,400｜实体 ~9.8 万｜关系 ~16.5 万；检索 2015–2025，聚焦数字病理 / 病理 AI
- 价值闭环一行：建库 → Gap 发现 → 方信数据可行性 → 研究方案

### P2 亮点① 高质量全文知识抽取

- 标题：不只抓摘要——全文级、可升级的知识抽取
- 要点：分章节 LLM 抽取；摘要→全文自动重抽；Method Role / 同义聚类；全文冷却重试与运维开关

### P3 亮点② 可信的空白发现

- 标题：多智能体辩论 + 记忆去重 + 证据可追溯
- 要点：三角色辩论；Ops Memory 软去重；证据内联溯源；任务质量 / 可迁移门控

### P4 亮点③ 落地闭环与运维

- 标题：从热点到方案——接本院数据、可周更
- 要点：周热点；方信 LIS API-faithful 可行性；Idea Pipeline；Gap UI 八标签 + 运维
- 收尾：下半年扩大高质量全文覆盖、强化可行性与方案落地验证

## 交付

- 格式：`.pptx`，约 4 页内容页（封面按所选模板能力决定）
- 文案：完整句，禁止省略号截断
- 产出路径建议：`fulltext_workflow/output/midyear_report_2026.pptx`

## 非目标

- 不展开完整管线操作手册
- 不承诺未验证的业务 ROI 数字
- 不做商业用途模板声明冲突时改用原创简洁版式
