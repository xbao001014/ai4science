# H&E 预测 Ki67 / 类似 IHC 短总览

**证据范围：** 轨 A 6 篇（其中 5 篇链至虚拟染色库总结，1 篇同一切片复染 Ki-67 全文）；轨 B 6 篇来自本地全文或手工补入 PDF。**非完备系统综述。**

## 1. 问题定义

Ki-67 等 IHC 标志物在病理诊断与分级中不可或缺，但额外染色成本高、流程长。深度学习方法试图从常规 H&E 推断 IHC 表型，形成两条主路线：

1. **虚拟染色（轨 A）**：学习 H&E→IHC 图像映射，再在生成图像上计 labeling index。
2. **直接预测（轨 B）**：跳过图像生成，从 H&E 直接回归分数或分类阳性状态。

二者评价标准不同：轨 A 须同时报告 **图像保真 + 定量指标一致性**；轨 B 以 **与 IHC 真值的相关/一致率** 为主。

## 2. 轨 A：虚拟染色

### Ki-67 核心

- **PMID 39087085** 在同一组织切片上构建 H&E 与 Ki-67 IHC 配对，比较 RGB/OD 空间与多种生成架构，并以 **Ki-67 labeling index** 作为临床相关终点。关键发现：intraslide 相关性可很高，但 **cross-case 泛化明显更难**——这对 NPC/Ki67 等跨中心应用是必提限制。
- **PMID 33784619（PC-StainGAN）** 处理 **无配对** H&E→Ki-67，引入病理一致性约束，适合缺乏配对的临床队列，但定量验证通常弱于配对研究。

### 类似 IHC 扩展

- **PMID 32238879（SOX10 虚拟 IHC）**：推进到单细胞核阳性状态，是「虚拟 IHC 不仅看像不像，还要看细胞表型」的早期代表。
- **PMID 40158294（虚拟 CD163）**：生成 + 分割 + M2-TAM 密度 + 预后，展示虚拟染色如何接入 **定量生物标志物发现**。
- **PMID 35810588（MVFStain）**：多功能染色映射，适合作为多标志物虚拟染色背景。
- **PMID 38148967**：口腔鳞癌组织先做 H&E、再复染 Ki-67，使用 Pix2Pix 生成合成 IHC，并按 Ki-67 阳性比例及多个阈值评价；同一切片复染减少了连续切片配准误差。

**轨 A 选用建议：** Ki-67 任务优先配对验证研究（39087085）；无配对数据看 33784619；需要细胞级标志物参考 32238879。

## 3. 轨 B：非生成式预测

| PMID | 任务 | 要点 |
|------|------|------|
| 32903653 | H&E→Ki-67 阳性细胞 | 早期细胞级代理预测，不依赖 IHC 输入 |
| 41250202 | H&E→Ki-67 回归 | Transformer 回归定量，乳腺癌 WSI |
| 39706861 | ER/PR/ERBB2 病例级预测 | CNN + Transformer-MIL；六队列；患者分流、第二读片及假阴性复核 |
| 35602213 | ER/PR/HER2 patch/slide 预测 | 37 站点数据并分析形态解释；局部到病例级性能存在落差 |
| 40256728 | H&E→PD-L1（MIL） | MIL 聚合 patch，连接 MIL 小综述 |
| 36347854 | H&E→PD-L1 分类 | 免疫治疗相关 IHC 代理 |

**轨 A vs 轨 B：**

- 轨 A 优势：可解释（可视 IHC）、可接现有 IHC 阅片流程；劣势：cross-case 泛化与计算成本。
- 轨 B 优势：端到端、部署轻；劣势：缺少「虚拟 IHC 图」中间产物，病理医生接受度因任务而异。

## 4. 评价与落地要点

1. **分层验证：** intraslide / cross-case / 外部中心须分开报告。
2. **终点选择：** Ki-67 优先 labeling index 或阳性比例，而非仅 PSNR/SSIM。
3. **肿瘤区定义：** 增殖指数对 ROI 敏感，需说明是否限制肿瘤区（可参考 PTM-NET 思路）。
4. **与 MIL 衔接：** slide 级 IHC 代理（如 PD-L1）常用 MIL 聚合 patch 特征（见 `mil-method-summary/`）。
5. **虚拟染色评价：** PMID 40603634 对 28 项研究进行综述并在 BCI/MIST 上 benchmark；连续切片错位可能使模糊图像在 SSIM/PSNR 上获益，视觉相似度不能替代生物标志物定量和下游任务验证。
6. **临床定位：** PMID 39706861 表明高特异度病例分流、IHC 第二读片和假阴性质量控制比“全面替代 IHC”更现实。
