## 二、论文整体概述

### 1. 核心问题
临床决策依赖于多模态数据，但临床环境中缺乏良好标注的多模态数据集，严重阻碍了能够有效整合多模态数据的AI模型的开发与临床应用。

### 2. 整体方法
研究开发了 MUSK（Multimodal transformer with Unified maSKed modeling），一个专为精准肿瘤学设计的视觉-语言基础模型。MUSK 采用两阶段预训练策略：第一阶段在5000万张病理图像和10亿个病理文本token上进行统一掩码建模（Unified masked modelling）；第二阶段在100万对病理图像-文本对上进行对比学习预训练，以高效对齐视觉和语言特征。结合针对病理领域的特定方法学适配，MUSK 能够在极少或无需进一步训练的情况下，胜任广泛的下游任务。

### 3. 主要贡献

1. 提出了 MUSK 视觉-语言基础模型，通过两阶段预训练（统一掩码建模与对比学习）有效利用大规模无标签、非配对的病理图像和文本数据。
2. 引入并验证了四项针对病理领域的特定方法学适配（病理特定图像增强、病理图像tokenizer、细粒度图像-文本解码器、自举对比学习），显著提升了模型在病理任务中的性能。
3. 在23个patch级别和slide级别基准测试中展示了卓越性能，并在黑色素瘤复发预测、泛癌预后预测及免疫治疗反应预测等真实临床结果预测任务中证明了其强大的应用潜力。

## 三、方法总结

### 方法 1：MUSK (Multimodal transformer with Unified maSKed modeling)

#### 1. 核心思想与解决的问题

- **目标问题**：解决病理领域高质量多模态标注数据稀缺的问题，构建一个通用的病理视觉-语言基础模型。
- **现有方法的局限**：传统自然图像预训练模型（如ImageNet预训练）在病理图像上表现次优；传统的图文对比学习仅考虑全局粗粒度对齐，且网络爬取的图文对常包含噪声。
- **核心思想**：采用“统一掩码建模 + 对比学习”的两阶段预训练范式，并引入病理领域特定的数据增强、Tokenizer、细粒度解码器和数据清洗策略，以学习鲁棒且细粒度对齐的多模态表征。
- **创新点**：
  1. **病理特定图像增强**：引入染色增强（RandStainNA）和多视野（FoVs，10x/20x/40x混合放大倍数）训练。
  2. **病理图像Tokenizer**：在TCGA数据上预训练专用的BEiT-v2图像Tokenizer，替代自然图像Tokenizer。
  3. **细粒度多模态解码器**：在对比学习基础上引入图像-文本解码器作为辅助损失，实现patch级和token级的局部细粒度对齐。
  4. **自举对比学习（Bootstrapped Contrastive Learning）**：利用基线模型过滤低相似度（<0.1）的噪声图文对，提升训练数据质量。

#### 2. 详细结构与数据流

- **输入**：
  - 图像：$512 \times 512$ 像素的病理 WSI patches（10x 放大倍数）。
  - 文本：病理相关的临床报告或文献文本。
- **数据预处理**：
  - 图像：组织分割，裁剪为不重叠的 $512 \times 512$ patches，保持原始分辨率。应用病理特定增强（RandStainNA，多FoV）。
  - 文本：使用 WordPiece 进行子词分词。
  - 图文对清洗：通过自举方法，使用基线模型计算相似度，过滤掉得分低于 0.1 的噪声样本。
- **单模态编码**：
  - 图像编码：基于 Vision Transformer。将图像划分为 patch，线性投影后，拼接可学习的 `[CLS]` token，并加上 1D 位置编码和图像类型编码。
  - 文本编码：基于 BERT 架构。分词后添加 `[BOS]` 和 `[SEP]` token，加上词嵌入、文本位置编码和文本类型编码。
- **跨模态融合**：
  - 采用基于 BEiT-3 的多模态 Transformer 主干。每个 Block 包含跨模态共享的多头自注意力（MSA）模块，以及根据输入模态切换的模态特定专家（MoME-FFN，即视觉 V-FFN 或语言 L-FFN），实现视觉和语言信息流的连接与融合。
- **处理流程**：
  1. **第一阶段（统一掩码预训练）**：在5000万病理图像和10亿文本token上，使用病理特定Tokenizer和增强进行掩码图像/文本建模。
  2. **第二阶段（对比学习预训练）**：在100万高质量图文对上，结合全局对比损失和细粒度图像-文本解码器辅助损失进行训练。
  3. **下游任务适配**：根据任务需求，使用冻结的编码器提取特征，通过余弦相似度（检索/零样本分类）、拼接特征+MLP（VQA）或线性探测（监督分类）进行预测。
- **输出**：多模态特征表示，或下游任务的具体预测结果（如分类标签、检索排序、生存风险评分）。
- **模块在整体网络中的位置**：单模态编码器位于网络前端，跨模态融合主干位于中间，下游预测头（如线性分类器、MLP）位于网络末端。
- **与其他模块的连接方式**：图像和文本的单模态编码输出作为序列输入到共享的 MSA 和 MoME-FFN 中进行融合；下游任务通过提取 `[CLS]` 或 `[BOS]` token 的全局特征，或拼接多模态特征输入到特定的预测头中。

#### 3. 数学公式

1. **图像输入表示**：
   $$ \pmb { H } _ { 0 } ^ { x } = [ \pmb { x } _ { [ \mathbb { C } \mathbb { L } \mathbb { S } ] } , \pmb { x } _ { i } ^ { p } , . . . , \pmb { x } _ { N } ^ { p } ] + \pmb { X } _ { p o s } + \pmb { X } _ { t y p e } $$
   其中，$\pmb { H } _ { 0 } ^ { x } \in \mathbb { R } ^ { ( N + 1 ) \times D }$ 为图像表示，$N = H W / P ^ { 2 }$ 为 patch 数量。

2. **文本输入表示**：
   $$ \pmb { H } _ { 0 } ^ { w } = [ \pmb { w } _ { [ \mathrm { B O S } ] } , \pmb { w } _ { i } , . . . , \pmb { w } _ { M } , \pmb { w } _ { [ \mathrm { S E P } ] } ] + \pmb { W } _ { p o s } + \pmb { W } _ { t y p e } $$
   其中，$\pmb { H } _ { 0 } ^ { w } \in \mathbb { R } ^ { ( M + 2 ) \times D }$ 为文本表示，$M$ 为分词后的单词长度。

3. **多模态 Transformer 主干前向传播**：
   $$ \begin{array} { r } { \pmb { H } _ { l } ^ { \prime } = \mathrm { M S A } \left( \mathrm { L N } \left( \pmb { H } _ { l - 1 } \right) \right) + \pmb { H } _ { l - 1 } } \\ { \pmb { H } _ { l } = \mathrm { M o M E } - \mathrm { F F N } \left( \mathrm { L N } \left( \pmb { H } _ { l } ^ { \prime } \right) \right) + \pmb { H } _ { l } ^ { \prime } } \end{array} $$
   其中，LN 为层归一化，MSA 为共享多头自注意力，MoME-FFN 为模态特定的前馈网络。

4. **跨模态检索相似度计算**（注：原文公式表述为 argmax，实际指代计算内积/余弦相似度以进行排序）：
   $$ s _ { i } = \mathrm { a r g m a x } \ \mathbf { u } _ { i } ^ { T } \mathbf { v } _ { j } $$
   其中，$\mathbf { u }$ 和 $\mathbf { v }$ 分别为图像和文本的嵌入向量。

#### 4. 输入输出维度

| 阶段 | 张量/变量 | 维度 | 说明 |

| 输入 | 图像 $\pmb { x }$ | $H \times W \times C$ | 原始图像分辨率，C为通道数 |

#### 6. 实现提示

- **关键网络组件**：Vision Transformer (图像), BERT (文本), BEiT-3 多模态 Transformer 主干 (共享 MSA + MoME-FFN)。
- **重要超参数**：图像 patch 大小 $512 \times 512$；VQA 线性分类器维度 2048；VQA 学习率 $lr = 0.001$，$\beta_1=0.9, \beta_2=0.98$，batch size 64，50 epochs，4000 warmup steps；自举对比学习噪声过滤阈值 0.1。
- **归一化/激活方式**：Layer Normalization (LN) 用于 Transformer 主干。
- **维度对齐方式**：图像和文本的嵌入维度 $D$ 统一为 1024（根据 VQA 拼接后为 2048 推断）。
- **实现注意事项**：需保持图像原始分辨率以支持多 FoV（多放大倍数）训练；必须使用病理特定的图像 Tokenizer 而非自然图像 Tokenizer。
- **依赖的特殊算子或第三方库**：torchscale, BEIT3 库, PyTorch Lightning, OpenSlide, Hugging Face Transformers, CLIP Benchmark。

## 四、论文级综合评价

### 1. 最值得借鉴的方法
- **自举对比学习（Bootstrapped Contrastive Learning）**：利用基线模型自动过滤网络爬取数据集中的噪声图文对，以极低的额外成本显著提升了对齐质量。
- **细粒度多模态解码器**：在传统的 CLIP 式全局对比损失之外，引入解码器辅助损失实现 patch-token 级别的局部对齐，有效提升了 VQA 和检索等需要细粒度理解的任务性能。

### 2. 方法之间的关系
两阶段预训练相辅相成：第一阶段的“统一掩码建模”利用海量无标签数据为图像和文本建立了强大的单模态基础表征和病理先验；第二阶段的“对比学习”则利用配对数据将这两个表征空间进行对齐。消融实验明确证明，缺少第一阶段会导致模型严重欠拟合，而缺少第二阶段的细粒度解码器则会损失跨模态任务的精度。

### 3. 复现可行性

- **代码是否公开**：未说明（本地文本未提供官方代码仓库链接，仅提及依赖的第三方开源库）。
- **方法描述是否完整**：非常完整。详细描述了数据构建、预处理、网络结构、预训练策略及下游任务配置。
- **关键配置是否明确**：明确。提供了硬件配置（64xV100）、数据规模、Patch大小、学习率、Batch size 等关键超参数。
- **预计复现难点**：1. 获取和处理 5000 万张 TCGA 图像 patches 及 10 亿文本 token 需要巨大的存储和工程 effort；2. 预训练需要至少 64 张 32GB V100 的算力支持；3. 缺乏官方开源代码可能导致细节（如 MoME-FFN 的具体实现、自举过滤的具体代码逻辑）难以完全对齐。

### 4. 与当前研究方向的关系

- **可直接采用的设计**：其病理特定的数据增强策略（RandStainNA + 多 FoV）、自举数据清洗流程，以及下游 WSI 分类中结合 AbMIL 和文本特征的融合范式。
- **需要改造的设计**：针对特定临床终点（如特定基因突变预测）的预测头设计；若算力受限，需探索更轻量级的 Tokenizer 或蒸馏策略。
- **可能形成的新研究思路**：探索在 WSI 级别直接进行图文细粒度对齐（而非仅在 patch 级别）；研究如何将 MUSK 的表征与患者纵向电子病历（EHR）时间序列数据结合，构建更全面的精准肿瘤学多模态模型。

### 5. 阅读备注
- 原文在公式(4)中使用了 $\mathrm{argmax}$ 来表示相似度计算，这在数学表达上存在瑕疵（通常 argmax 返回索引，而此处语境应为计算内积/余弦相似度），阅读和复现时应理解为计算特征向量的点积或余弦相似度以进行排序。
