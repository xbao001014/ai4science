## 二、论文整体概述

### 1. 核心问题
现有的多模态癌症分类方法大多基于晚期融合，忽略了多模态特征之间的深层交互信息；同时在病理图像分析中，现有方法要么依赖病理学家手动勾画感兴趣区域（ROI），要么在弱监督设置下丢弃大量包含噪声标签的图像块（patches），未能充分利用全切片图像（WSI）级别的标签信息。

### 2. 整体方法
提出一个集成框架，包含两个主要部分：
1. **PathIn-NL（基于噪声标签学习的病理实例编码器）**：一种弱监督模型，将WSI级别的patch分类建模为噪声标签问题，通过自训练策略清洗标签，从而充分利用所有patch和WSI级标签提取病理特征。
2. **AHM-Fusion（基于注意力的层次化多模态融合模型）**：一种通用的多模态融合方法，包含早期特征引导模块和晚期特征融合模块，通过多层注意力机制捕获模态间的深层交互信息，并控制各模态表示的表达力。

### 3. 主要贡献
1. 提出了一种新颖的弱监督模型 PathIn-NL，能够利用 WSI 级标签自动从高分辨率 WSIs 中提取 patch 特征，摆脱了对 WSI 尺寸和肿瘤占比的限制。
2. 提出了一种新的多模态融合模型 AHM-Fusion，能够通过多层注意力机制捕获深层交互信息，并通过双向特征引导模块在单模态网络训练时共享信息，引导模型关注高维数据中的重要区域。
3. 在 TCGA 胶质瘤和肺癌两个基准数据集上评估了该框架，在所有数据集上均取得了优于现有最先进方法（SOTA）的性能。

## 三、方法总结

### 方法 1：基于噪声标签学习和注意力机制的层次化多模态融合框架

#### 1. 核心思想与解决的问题

- **目标问题**：在仅有 WSI 级标签的条件下，提取高质量的病理 patch 特征，并实现病理图像与基因组数据的深层多模态融合以进行癌症分类。
- **现有方法的局限**：传统方法多采用晚期融合，导致提取的模态特征缺乏相关性，模态交互信息未被充分利用；病理分析中手动勾画 ROI 耗时且主观，而现有的弱监督方法（如 top-k 选择）会丢弃困难样本，导致性能下降。
- **核心思想**：将病理 patch 分类视为典型的噪声标签问题，利用自训练框架交替优化网络参数和软标签以清洗噪声；在多模态融合阶段，引入双向早期特征引导和基于门控的晚期融合机制，实现多层次的模态交互。
- **创新点**：
  1. 提出 PathIn-NL，利用自训练策略自动清洗 patch 级别的噪声标签，引入监督信息而不丢弃困难样本。
  2. 提出 AHM-Fusion，突破传统晚期融合限制，通过双向早期特征引导模块在特征聚合阶段捕获模态交互，并通过门控机制控制模态表达力。

#### 2. 详细结构与数据流

- **输入**：
  - 病理图像：WSI 切割后的非重叠 patch（512×512×3）。
  - 基因组数据：CNV 数据（60,446 个基因）。
- **数据预处理**：
  - 病理：使用 Otsu 算法提取组织掩码，丢弃组织区域像素占比少于 25% 的 patch。后续进行归一化、随机翻转和颜色抖动。
  - 基因组：缺失值填充为 -1。
- **单模态编码**：
  - 病理编码（PathIn-NL + WSI聚合）：PathIn-NL（7个残差块、1个全局平均池化、2个全连接层）提取 patch 特征。随后通过 WSI 级聚合模块（5层 SAGEConv 的 GCN + 门控注意力机制）将 patch 特征聚合为 WSI 级特征。
  - 基因组编码（SNN）：使用自归一化网络（SNN），通过一个 2560 节点的全连接层（ELU 激活 + Alpha Dropout）将数据转换为 10×256 形式，再通过门控注意力机制聚合。
- **跨模态融合**：
  - 早期特征引导：基因组特征引导病理特征聚合，同时病理特征（WSI级）引导基因组特征聚合（双向注意力）。
  - 晚期特征融合：通过级联的双注意力机制层（ATT block）进一步捕获深层交互，随后使用基于门控的注意力机制控制各模态特征的表达力，最后拼接并输入分类器。
- **处理流程**：
  1. 数据预处理与 Patch 切割。
  2. PathIn-NL 训练：先进行 Backbone learning（交叉熵损失，较大学习率），然后进行 Noisy label cleaning（交替优化网络参数和软标签）。
  3. 单模态特征提取与聚合（冻结单模态网络，保存特征）。
  4. AHM-Fusion 多模态融合与最终分类预测。
- **输出**：癌症亚型或分级的分类概率分布。
- **模块在整体网络中的位置**：PathIn-NL 位于病理特征提取的最前端；AHM-Fusion 位于单模态特征提取之后、最终分类器之前。
- **与其他模块的连接方式**：PathIn-NL 输出的 WSI 级病理特征与 SNN 输出的基因组特征共同输入 AHM-Fusion；AHM-Fusion 输出的加权多模态特征拼接后输入全连接分类器。

#### 3. 数学公式

- **噪声标签清洗损失**：
  软标签更新：$\hat{y}_{t+1} = \text{Softmax}(f(\theta, x_t))$
  软标签损失：$L_{soft} = \frac{1}{n} \sum_{j=1}^n KL(s(\theta, x_i) \| \hat{y}_i)$，其中 $s(\theta, x_i) = \text{Softmax}(f(\theta, x_i))$
  硬标签损失：$L_{hard} = -\frac{1}{n} \sum_{i=1}^n \sum_{j=1}^c \tilde{y}_{ij} \log s_j(\theta, x_i)$
  总损失：$L_{total} = \lambda L_{hard} + (1 - \lambda) L_{soft}$

- **WSI 级聚合**：
  $P^{(i)} = \text{GCN}(H^{(i)}) \in \mathbb{R}^{n_i \times d}$
  $A = \tanh(V P^{(i)T}) \otimes \text{Sigmoid}(U P^{(i)T})$
  $P_{agg}^{(i)} = \sum_{k=1}^{n_i} \text{Softmax}(A_k) P_k^{(i)}$

- **早期特征引导（以基因组引导病理为例）**：
  $A_{G \to P} = \text{Softmax}\left(\frac{W_q G P^T W_k^T}{\sqrt{d_k}}\right)$
  $\tilde{P} = A_{G \to P} W_v P$

- **晚期特征融合（门控机制）**：
  $Z_G = \text{Sigmoid}([\tilde{P}'', \tilde{G}''] W_1)$
  $O_G = Z_G \otimes \text{ReLU}(W_2 \tilde{G}'')$
  （注：$[\cdot]W$ 表示带权重矩阵的线性变换，实验中实现为 `torch.nn.Bilinear`）

#### 6. 实现提示

- **关键网络组件**：残差块（PathIn-NL）、图卷积网络（SAGEConv）、自归一化网络（SNN）、Transformer 注意力机制（ATT block）。
- **重要超参数**：Patch 大小 512×512，组织区域阈值 25%，$\lambda=0.33$，Backbone 学习率 1e-3，Cleaning/Fusion 学习率 1e-4。
- **归一化/激活方式**：ReLU（GCN, 门控），ELU（SNN），Sigmoid（门控注意力），Softmax（注意力权重）。
- **维度对齐方式**：通过全连接层将基因组数据映射为 10×256；在早期引导中，使用聚合后的 1×256 WSI 级病理特征引导基因组特征，以避免维度变化和过拟合。
- **实现注意事项**：PathIn-NL 需要严格交替优化网络参数和软标签；早期引导模块中，基因组引导病理时使用的是聚合前的 $M \times 256$ 特征，而病理引导基因组时使用的是聚合后的 $1 \times 256$ 特征。
- **依赖的特殊算子或第三方库**：PyTorch, torchvision, `torch.nn.Bilinear`（用于门控机制的线性变换）。

#### 8. 适用场景与可迁移性

- **原论文应用场景**：TCGA 肺癌亚型分类（LUAD/LUSC）和胶质瘤分级（GBM/LGG）。
- **可迁移到的任务/数据集**：其他具有 WSI 和基因组/临床数据的多模态癌症分类、分级或预后预测任务。
- **迁移所需调整**：需调整 patch 切割参数、GCN 图构建的邻接关系、基因组数据预处理及维度映射层。
- **适用条件**：拥有 WSI 级标签但缺乏 patch 级标注的数据集；存在多模态数据且模态间存在潜在交互。
- **潜在限制**：早期特征引导模块的计算成本可能随任务复杂度变化；对于噪声率极低的数据集，PathIn-NL 相比普通交叉熵的优势不明显。

#### 9. 实验与消融证据

- **主要性能结果**：在 TCGA-LUAD/LUSC 上 AUC 达 0.977，在 TCGA-GBM/LGG 上 AUC 达 0.872。
- **相对基线的提升**：相比单模态和传统晚期融合（Concat, Tensor），AHM-Fusion 在 AUC 和 AP 上均有提升（如胶质瘤分级 AUC 提升 6.5% 以上）。PathIn-NL 相比 ImageNet 预训练和 MAE/Truncated $L_q$ 损失在肺癌任务上显著提升。
- **相关消融实验**：
  1. **早期特征引导模块消融**：双向引导在胶质瘤任务上最优；在肺癌任务上，单向基因组引导与双向引导性能相当。
  2. **晚期特征融合模块消融**：级联 ATT block 和门控注意力机制均能独立提升性能，联合使用达到最佳结果。
- **作者结论**：PathIn-NL 能有效利用 WSI 标签并清洗噪声；AHM-Fusion 能捕获多模态深层交互，双向引导在复杂任务（如胶质瘤分级）中更有效。
- **证据是否充分**：是，提供了多数据集对比、与 SOTA 方法的对比以及详细的模块消融实验。

## 四、论文级综合评价

### 1. 最值得借鉴的方法
将 WSI patch 分类建模为噪声标签问题并通过自训练清洗标签的策略（PathIn-NL），以及多模态融合中的双向早期特征引导机制。前者有效解决了弱监督下 patch 标签不一致的问题，后者突破了传统晚期融合无法在特征聚合阶段进行模态交互的局限。

### 2. 方法之间的关系
PathIn-NL 负责解决病理图像弱监督特征提取问题，为多模态融合提供高质量、去噪的病理特征；AHM-Fusion 负责解决多模态特征交互问题。两者串联构成完整的分阶段训练框架，PathIn-NL 的输出是 AHM-Fusion 的关键输入。

### 4. 与当前研究方向的关系

- **可直接采用的设计**：基于门控的晚期多模态融合机制、噪声标签清洗的自训练框架。
- **需要改造的设计**：基因组数据的 SNN 处理模块可能需要根据具体基因数据类型（如 mRNA、突变）进行调整；GCN 的图构建方式需根据具体 WSI 分辨率和 patch 大小重新设计。
- **可能形成的新研究思路**：探索自适应的早期特征引导策略以平衡性能与计算成本（如根据任务复杂度动态选择单向或双向引导）；将噪声标签学习扩展到其他弱监督多模态任务（如生存预测）。

### 5. 阅读备注
论文在讨论部分坦诚了局限性，如早期引导模块在简单任务（肺癌亚型分类）中可能浪费计算资源，以及 PathIn-NL 在低噪声率下优势不明显。这为后续研究（如自适应引导策略、不同噪声率下的评估）提供了明确方向，体现了严谨的科研态度。
