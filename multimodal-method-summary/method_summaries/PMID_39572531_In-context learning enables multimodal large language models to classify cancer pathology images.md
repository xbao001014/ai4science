## 二、论文整体概述

### 1. 核心问题
医学图像分类通常依赖大量标注数据进行从头训练或微调视觉基础模型，这一过程计算和技术成本高昂。上下文学习（In-context learning, ICL）在自然语言处理中展现了无需参数更新即可学习的能力，但在医学图像分析中的潜力尚未被充分探索。

### 2. 整体方法
本研究系统评估了多模态大语言模型 GPT-4V 在癌症病理图像处理中的上下文学习能力。通过构建包含少量示例图像的 Prompt（Few-shot prompting），引导 GPT-4V 进行图像分类。研究提出并对比了随机采样和基于 k 近邻（kNN）的特征相似度采样策略来构建 few-shot 示例，并在三个组织病理学基准数据集上评估了其性能，同时分析了多模态推理对文本语义空间的影响。

### 3. 主要贡献

1. 证明了基于图像的上下文学习（ICL）能够显著提升多模态大模型在病理图像分类中的性能，使其匹配甚至超越经过专门微调的窄带图像分类器。
2. 提出并验证了基于 kNN 的图像特征检索采样策略，通过选择与目标图像语义最相似的示例，进一步提升了 ICL 的分类准确率。
3. 揭示了 VLM 的 ICL 能够改善模型文本推理的语义聚类，缩小了通用基础模型与病理专用基础模型（如 Phikon, UNI）之间的性能差距，并提供了多模态推理的可解释性分析。

## 三、方法总结

### 方法 1：基于 GPT-4V 与 kNN 图像检索的病理图像上下文学习分类框架

#### 1. 核心思想与解决的问题

- **目标问题**：降低医学图像分类对大规模标注数据和模型微调的依赖，利用通用多模态大模型的上下文学习能力实现高效分类。
- **现有方法的局限**：传统的视觉基础模型需要大量领域特定数据进行微调，且每次新任务都需要重新训练；纯文本的 ICL 方法（如 MedPrompt）无法处理医学中高度多模态的数据（如影像）。
- **核心思想**：将自然语言处理中的 few-shot prompting 扩展至视觉领域，通过向 GPT-4V 提供少量带有标签的示例图像，使其在无需参数更新的情况下学习分类任务。利用外部视觉编码器提取特征，通过 kNN 检索最相关的示例图像来优化 Prompt 构建。
- **创新点**：将 kNN 图像检索机制引入 VLM 的 ICL Prompt 构建中，并验证了其在病理多分类任务中的有效性；通过强制 JSON 格式输出结合思维链（CoT），实现了多模态推理过程的可解释性分析。

#### 2. 详细结构与数据流

- **输入**：病理图像 tiles（测试图像及用于 few-shot 的候选图像集）。
- **数据预处理**：从公开数据集中随机抽取平衡的测试集（MHIST 和 PCAM 各 60 个样本，CRC100K 120 个样本）；MHIST 数据限制为专家共识一致的图像；排除同患者图像以防止患者固有形态特征成为混淆因素。
- **单模态编码**：
  - **图像特征编码（用于检索）**：使用 Phikon (ViT-B 40M Pancancer) 的 teacher backbone 提取图像特征，生成 768 维的一维特征向量。
  - **文本特征编码（用于分析）**：使用 Ada-002 模型将 GPT-4V 输出的文本推理转换为文本嵌入。
  - **多模态编码（用于推理）**：GPT-4V 内部的视觉和语言编码器处理输入的图像和文本 Prompt。
- **跨模态融合**：GPT-4V 原生的多模态注意力机制，将文本 Prompt（包含指令、示例图像标签、测试图像）与输入的测试图像进行联合表征和推理。
- **处理流程**：
  1. 使用 Phikon 提取训练集和测试集所有图像 tiles 的 768 维特征向量。
  2. 对于每个测试图像，计算其与训练集图像的余弦相似度，为每个可能的目标标签选取最相似的 $k$ 个图像（$k=1, 3, 5, 10$）。
  3. 构建 System Prompt（设定假设场景以绕过医疗拒绝策略，要求 JSON 格式输出包含 thoughts, answer, score）和 User Prompt（按顺序输入 $k$ 个示例图像及其标签，随后输入测试图像，并引导 CoT 推理）。
  4. 调用 GPT-4V API 进行推理，获取 JSON 格式的分类结果。
- **输出**：JSON 格式的文本，包含逻辑推理过程（thoughts）、最终分类答案（answer）和置信度分数（score）。
- **模块在整体网络中的位置**：Phikon 作为外部辅助特征提取器位于数据准备阶段；GPT-4V 作为核心推理引擎位于预测阶段。
- **与其他模块的连接方式**：Phikon 输出的特征向量用于计算余弦相似度，筛选出的图像作为多模态输入传递给 GPT-4V；GPT-4V 输出的文本传递给 Ada-002 进行语义空间分析。

#### 9. 实验与消融证据

- **主要性能结果**：在 10-shot kNN 设置下，GPT-4V 在 MHIST 上达到 83.3% 准确率，在 PCAM 上达到 88.3% 准确率。
- **相对基线的提升**：Zero-shot 准确率仅略高于随机猜测（如 MHIST 56.7%）；引入 few-shot 后性能持续提升；kNN 采样显著优于随机采样（如 PCAM 10-shot 下 kNN 达 88.3%）。
- **相关消融实验**：对比了 zero-shot、random few-shot、kNN few-shot 在不同 shot 数量（1, 3, 5, 10）下的表现；对比了与专门训练的 CNN/ViT 模型（ResNet, ViT-Tiny/Small）及病理基础模型（Phikon, UNI）的性能。
- **作者结论**：ICL 能够匹配或超越微调的专用图像分类器；kNN 采样能有效提升 ICL 性能；ICL 显著缩小了通用 VLM 与病理专用基础模型之间的性能差距。
- **证据是否充分**：在三个公开基准数据集上进行了验证，但受限于 API 预览状态，测试样本量较小（60-120个），且未采用集成（ensembling）方法，证据强度中等。

## 四、论文级综合评价

### 1. 最值得借鉴的方法

### 5. 阅读备注
需注意该研究受限于 GPT-4V preview API 的速率和上下文窗口限制，未能测试更大规模的 few-shot 样本，也未采用集成方法。此外，模型在识别碎片（debris）、黏液（mucus）和基质（stroma）等类别时表现不佳，提示了当前通用 VLM 在细粒度病理形态学特征理解上仍存在局限性。
