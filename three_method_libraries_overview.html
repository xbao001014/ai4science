一、选取范围

三个模块共用“病理场景 + 方法贡献 + 可核验证据”的边界，但各自回答不同研究问题。

多模态融合

35 篇 · 2018–2026

关注病理图像与其他信息源的联合表示、对齐、交互和联合预测，而不是单张病理图像内部的多尺度特征融合。

  • 病理 + 基因组 / 转录组 / 空间组学
  • 病理 + 临床变量 / 放射影像
  • 病理图像 + 文本、报告与视觉语言预训练
  • 缺失模态鲁棒融合与多模态基础模型

病理图像分割

38 篇 · 2016–2026

关注组织病理、细胞病理和明场显微图像中可输出掩码的方法，覆盖语义、实例及联合任务。

  • 细胞核、全细胞与腺体实例分割
  • 肾小球、组织区域和肿瘤区域分割
  • 检测—分割—分类联合建模
  • 弱监督、交互式、跨染色及基础模型

虚拟染色

39 篇 · 2017–2026

关注具有明确目标染色含义的图像生成，包括无标记成像到 H&E、染色间转换与虚拟 IHC / 多重染色。

  • 相位、光声、自体荧光等无标记输入
  • 配对、无配对、弱配对与多域转换
  • 结构保持、错位鲁棒和 WSI 扩展
  • 临床可读性、定量标志物与可信验证

二、选取原则

引用用于发现代表作，全文证据决定能否进入完整方法总结。

高引与创新双通道既保留奠基性、高引用论文，也纳入引用尚未积累但在对齐、生成、泛化或可信评价上有明确创新的近期工作。
病理场景为必要条件输入或输出必须涉及组织病理、细胞病理、数字病理或相关组织学成像；纯自然图像、纯放射或主题邻接工作不直接纳入。
核心贡献必须属于主题分割不能只是普通预处理；虚拟染色必须生成具有目标染色语义的图像；多模态必须存在真正的跨模态联合建模。
全文证据优先只有本地全文或人工核验 PDF 足以确认结构、训练、数据流和实验设计时，才生成与正式论文同等级的完整总结。
创新需经基线与消融核验区分“增加了一个模态/数据源”和“提出了新机制”；核查单模态、简单拼接、模块消融、外部验证及复现信息。
禁止跨论文粗暴排名不同数据集、标注协议、划分和指标不可直接比较；引用、Dice、AJI、PQ 或视觉相似度均不单独代表方法优越性。

五、当前涵盖内容总结

方法库已经从“代表作清单”扩展为可用于方法选型、基线设计和研究缺口识别的结构化知识底座。

MULTIMODAL

融合机制主干已形成

覆盖早期特征拼接和联合生存网络、门控与 Kronecker 交互、协同注意力与 Transformer、多尺度放射—病理融合、病理视觉语言对齐、空间组学桥接，以及缺失模态条件下的鲁棒学习。库内同时保留单模态 WSI 基础模型和受控比较论文作为评价坐标。

SEGMENTATION

任务、监督和架构三条线并行

从早期边界感知核分割、腺体实例分割和 U-Net 系方法，扩展到 HoVer 类联合分割—分类、点标注与交互式方法、跨染色泛化、扩散分割、CellViT / CellSAM / SegAnyPath，以及 MoNuSeg、CoNIC 等数据和挑战基准。

VIRTUAL STAINING

从视觉转换走向临床可信性

覆盖 CycleGAN 类无配对转换、对比学习和扩散归一化、无标记相位/光声/自体荧光成像、虚拟 IHC 与多重染色、WSI 无缝合成、错位鲁棒生成，以及病理医师判读、标志物定量和外部临床验证。

STRUCTURED EVIDENCE

每篇论文保持统一证据结构

逐篇总结统一记录元数据、核心问题、详细结构与数据流、公式和维度、实现提示、资源开销、迁移条件、实验与消融、方法评价、复现难点及证据不足项；伪代码栏目按当前约定保留为空。

六、证据边界与使用方式

方法库适合做研究导航和比较框架，不等同于跨论文排行榜或临床指南。

核心判断

“有全文”不等于“所有细节都可恢复”；每篇总结以本地可核验文本为边界。缺少公式、精确维度、参数量或外部验证时，明确标记“未说明”或“本地证据不足”。

  • 引用数是带日期的 OpenAlex / 本地快照，只用于候选发现与排序，不作为创新性结论。
  • 不同论文的数据集、病例构成、划分策略、扫描设备、标注和指标不同，不进行直接数值排名。
  • 基准/数据集、算法、临床验证、基础模型和使用范式应分角色比较，避免把资源贡献写成网络创新。
  • 虚拟染色的像素相似度不能代替病理诊断一致性；多模态性能增益需排除信息量增加和数据泄漏；分割需关注实例级与跨域泛化。
  • 推荐先用 overview 建立谱系，再进入逐篇 summary 核验结构、训练和实验细节，最终回看原始全文。
